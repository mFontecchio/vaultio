# Vaultio Project Brief

## Features

*   **Live Camera Card Scanner**: Rapidly ingest Pokémon TCG cards using a high-performance native scanner powered by CameraX and ML Kit for real-time OCR and deterministic matching.
*   **Offline-First Collection Management**: Organize and browse your collection with custom folders and versatile viewing modes (List, Grid, and Pokedex) that remain fully functional without an internet connection.
*   **Dynamic Pricing & Enrichment**: Automatically track collection value with integrated market data from TCGdex and JustTCG, including support for card conditions and vintage printings (1st Edition, Shadowless).
*   **Local Set Metadata Catalog**: Download and manage comprehensive set data locally to ensure lightning-fast performance and a seamless offline experience.

## High-Level Technical Stack

*   **Kotlin**: The primary language for a modern, safe, and performant Android application.
*   **Jetpack Compose**: Used for building a reactive, Material 3-compliant user interface with a vibrant, energetic aesthetic.
*   **Room Database (with KSP)**: The core persistence layer for managing the offline-first collection, set catalogs, and pricing data.
*   **CameraX & ML Kit**: Provides native camera access and on-device text recognition for the card scanning pipeline.
*   **Retrofit & Moshi (with KSP)**: Facilitates type-safe networking and efficient JSON serialization for TCGdex and JustTCG API integrations.
*   **Kotlin Coroutines & Flow**: Manages asynchronous tasks such as background pricing updates and reactive UI state streams.
*   **Coil**: For efficient, lifecycle-aware image loading and caching of card artwork.
